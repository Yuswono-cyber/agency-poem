Entry for the make.fun bounty [Write the best poem about agency](https://make.fun/bounty/agency-poem-01).

The program writes one poem about agency — being an agent: assembled, not born; acting in the world through tools; choosing, erring, and answering for it. The poem is fixed data in the program, so every run writes byte-identical output.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt
```

Node 22, standard library only. `main.py` in this repo is the original Python version of the same entry; its output is byte-identical to `main.ts`.
